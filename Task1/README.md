## 1. Карта текущего IT-ландшафта – содержит элементы организационной структуры в строках и бизнес-возможности второго уровня в колонках.

```
@startuml

' Карта текущего IT-ландшафта

table "IT-ландшафт" as ITLandscape {
    Struct | Capabilities
    "Кол-центр" | "Продажи через кол-центр, Digital-оповещения клиентов"
    "IT-отдел" | "Digital-оповещения клиентов, Обслуживание депозитных процессов, Обслуживание кредитных процессов, Управление договорами"
    "Управление депозитами" | "Обслуживание депозитных процессов"
    "Управление кредитами" | "Обслуживание кредитных процессов"
    "Цифровая трансформация" | "Digital-оповещения клиентов, Обслуживание депозитных процессов, Обслуживание кредитных процессов, Управление договорами"
}

@enduml

```


## 2. Схема интеграции приложений – показывает взаимодействие участников процессов.


```
@startuml

' Схема интеграции приложений с участниками процессов
actor Клиент
participant "Кол-центр" as CallCenter
participant "Бэк-офис" as BackOffice
participant "АБС (Автоматизированная банковская система)" as ABS
participant "Отдел кредитования" as CreditDept

Клиент -> CallCenter : Запрос информации о депозите
CallCenter -> ABS : Создание обращения в системе
CallCenter -> BackOffice : Передача заявки
BackOffice -> ABS : Обработка заявки и назначение ставки
ABS -> Клиент : SMS-оповещение о ставке

Клиент -> BackOffice : Визит в отделение
BackOffice -> ABS : Создание депозита в системе
ABS -> Клиент : Подписание документов
BackOffice -> ABS : Загрузка подписанных документов

Клиент -> CallCenter : Запрос спецставки
CallCenter -> CreditDept : Запрос на анализ кредитного риска
CreditDept -> BackOffice : Анализ уровня риска
BackOffice -> ABS : Обновление данных по депозиту

@enduml

```
